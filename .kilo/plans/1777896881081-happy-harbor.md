## 10. Error Handling Pattern

Every safeParse MUST have clear error messages:

```typescript
const parsed = SomeSchema.safeParse(data)
if (!parsed.success) {
  throw new Error(
    `Invalid ${schemaName} at ${filePath}: ${parsed.error.message}\n` +
    `Issues: ${JSON.stringify(parsed.error.errors, null, 2)}`
  )
}
```

This ensures when validation fails, we know exactly which file and why.

## 11. Handling Unknown/Extra Fields in JSON

**Problem:** Existing config JSON files may have fields not in our schema.

**Approach: Strict with passthrough for discovery**

1. Start with strict schemas (no `.passthrough()`)
2. If validation fails, check if it's due to unknown fields
3. If unknown fields exist, use `.passthrough()` temporarily to allow them
4. After review, either:
   - Add the field to the schema properly
   - Or acknowledge it's legacy and strip it from JSON

**For `protocolSpecific` field specifically:**
```typescript
// Currently: z.record(z.string(), z.unknown())
// This allows ANY structure under protocolSpecific

// If we need strict validation of known protocol sections:
// protocolSpecific: z.object({
//   aaveV3: z.object({ pool: AddressSchema, rewards: AddressSchema }),
//   morpho: z.object({ blue: AddressSchema, ... }),
//   // ... all known protocol sections
// })
```

**Recommended:** Keep `protocolSpecific: z.record(z.string(), z.unknown())` for now since it varies widely. Only validate the structure we know is consistent.

## 12. Testing Strategy

Before implementing, create a test to validate existing JSON files:

```typescript
// scripts/helpers/test-schemas.ts
import { readdirSync } from 'fs'
import path from 'path'
import { BaseConfigSchema, FleetConfigSchema, FleetDeploymentSchema } from './zod-schemas'

const configPath = path.resolve(__dirname, '../../config')
const fleetsConfigPath = path.resolve(__dirname, '../../config/fleets')
const deploymentsPath = path.resolve(__dirname, '../../deployments/fleets')

function validateJsonFiles(dir: string, schema: z.ZodType<any>, name: string) {
  const files = readdirSync(dir).filter(f => f.endsWith('.json'))
  for (const file of files) {
    const raw = fs.readFileSync(path.join(dir, file), 'utf8')
    const parsed = schema.safeParse(JSON.parse(raw))
    if (!parsed.success) {
      console.error(`${name}/${file} failed:`, parsed.error.message)
    }
  }
}

validateJsonFiles(configPath, ConfigSchema, 'config')
validateJsonFiles(fleetsConfigPath, FleetConfigSchema, 'fleets')
validateJsonFiles(deploymentsPath, FleetDeploymentSchema, 'deployments')
```

This ensures all existing JSON files pass validation before we consider the work complete.
