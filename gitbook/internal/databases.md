# Databases

All database packages live in `summerfi-monorepo/packages/`. Each package exposes a Kysely-typed client (generated by `kysely-codegen`) and a set of Kysely migrations. None of them use Prisma — schema types are generated from live database introspection.

## Package index

| Package | npm name | Purpose |
|---|---|---|
| `app-db` | — | Main application database (minimal content in current checkout — only `node_modules` present) |
| `borrow-db` | `@summerfi/borrow-db` | Ajna rewards and borrow position tracking |
| `summer-protocol-db` | `@summerfi/summer-protocol-db` | Protocol-level operational data |
| `summer-institutions-db` | `@summerfi/summer-protocol-institutions-db` | Institution feedback and admin portal data |
| `summer-beach-club-db` | `@summerfi/summer-beach-club-db` | Points/beach-club loyalty program |

## borrow-db (`@summerfi/borrow-db`)

**Query client**: Kysely + `kysely-postgres-js`

Tracks Ajna rewards and cross-protocol borrow positions. Key tables derived from generated types:

- `AjnaRewardsDailyClaim` — per-address daily Ajna reward claims with `chainId`, `poolAddress`, `amount`, `source` (`core | bonus`), `type` (`borrow | earn`), `weekNumber`, `dayNumber`
- Additional position and vault tables for protocols including `aavev2`, `aavev3`, `ajna`, `maker`, `morphoblue`, `sky`, `sparkv3`

Enum types: `Protocol`, `Product` (`borrow | earn | multiply`), `VaultType`, `AjnaRewardsSource`, `AjnaRewardsPositionType`.

### Regenerate types

```bash
pnpm -F @summerfi/borrow-db codegen
# runs: kysely-codegen --camel-case --out-file ./src/database-types.ts
```

## summer-protocol-db (`@summerfi/summer-protocol-db`)

Stores protocol-level operational data indexed from on-chain events and the subgraph. Key tables:

- `ArmadaDcaOrders` — DCA order state (`orderId`, `fromVault`, `toVault`, `amount`, `intervalSeconds`, `maxTrades`, `status`, `tradesExecuted`, `nextExecutionAt`, …)
- `Campaigns` — user participation in partner campaigns (e.g. OKX)
- `DailyFleetInterestRate` — daily average interest rates per fleet per network
- `DailyRewardRate` — daily average reward rates

Network enum: `arbitrum | base | hyperliquid | mainnet | optimism | sonic`.

Contains a `migrations/` directory and helper scripts for running migrations.

## summer-institutions-db (`@summerfi/summer-protocol-institutions-db`)

Stores data for the institutions admin portal. Key tables:

- `Institutions` — registered institution records
- `FeedbackMessages` — threaded feedback with `category` (`bug | feature-request | question`), `status` (`new | in-progress | resolved | closed`), and `authorType` (`user | admin | system`)
- `GlobalAdmins` — super-admin accounts identified by `userSub`

User roles: `Viewer | RoleAdmin | SuperAdmin`.

## summer-beach-club-db (`@summerfi/summer-beach-club-db`)

Stores the points/beach-club loyalty program. Key tables:

- `DailyStats` — per-referral daily stats (`active_users`, `points_earned`, `total_deposits`)
- `MerchandiseSignatures` — signed claims for merchandise redemptions
- `PointsConfig` — configurable point multipliers and descriptions

Note: this package uses snake_case column names (Kysely codegen without `--camel-case`), unlike the other packages which use camelCase.

## Common patterns

All packages follow the same structure:

```
<package>/
├── src/
│   ├── database-types.ts   # Generated by kysely-codegen — do not edit
│   ├── helpers.ts          # Query helpers
│   ├── index.ts            # Re-exports client and types
│   └── migrations/         # Kysely migration files
├── package.json
└── tsconfig.build.json
```

Build:

```bash
pnpm -F @summerfi/<package-name> build
# tsc -b --preserveWatchOutput -v tsconfig.build.json
```

The database connection string is not stored in these packages — it is injected at runtime by the consuming application via environment variable.
